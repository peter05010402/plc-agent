# 需求：泵站离心泵启停控制（S7-1500 / SCL）

## 1. 工艺描述

泵站 1 台离心泵由接触器 KM1 驱动，现场有启动/停止按钮、急停按钮、电机过载保护器与低液位开关。
设备支持手动与自动两种模式：自动模式下只要液位低就允许自动启动补液；手动模式下必须人工按启动。
急停按下或电机过载时，泵必须立即停机并锁存故障，故障未人工复位前不得再次启动。

## 2. IO 清单

| 地址 | 符号名 | 数据类型 | 说明 |
|---|---|---|---|
| %I0.0 | StartBtn | Bool | 启动按钮（常开，点动） |
| %I0.1 | StopBtn | Bool | 停止按钮（常开） |
| %I0.2 | EStop | Bool | 急停回路（常闭，TRUE = 正常） |
| %I0.3 | Overload | Bool | 电机过载（常开，TRUE = 过载） |
| %I0.4 | AutoMode | Bool | 自动模式选择 |
| %I0.5 | LevelLow | Bool | 液位低，允许启动 |
| %Q0.0 | MotorRun | Bool | KM1 接触器线圈 |
| %Q0.1 | RunLamp | Bool | 运行指示灯 |
| %Q0.2 | FaultLamp | Bool | 故障指示灯 |
| %QW2 | FaultCode | Int | 故障码（0=正常，1=急停，2=过载） |

## 3. 控制要求

1. 安全条件 = 急停回路闭合且未过载；安全条件丢失必须在同一扫描周期内切断电机输出。
2. 启动：安全条件满足且非故障锁存时，按启动按钮置运行位并自保持；停止按钮优先于启动。
3. 启动许可：手动模式下需液位低才允许启动；自动模式下液位低自动启动。
4. 故障：急停或过载触发后锁存故障位、记录故障码，输出全部回到安全态。
5. 复位：安全条件恢复后按停止按钮，清除故障锁存与故障码，但不得自动重启电机。
6. 故障指示灯在故障锁存期间以约 1 Hz 闪烁，运行指示灯跟随运行位。

## 4. 约束

- 目标 PLC：S7-1500，TIA Portal V18，编程语言 SCL。
- 开启优化块访问，逻辑封装为 FUNCTION_BLOCK，不自带 OB1 调用代码。
- 定时器使用 IEC TON，实例声明在静态区。
- 交付物需包含 IO 表与测试计划。
