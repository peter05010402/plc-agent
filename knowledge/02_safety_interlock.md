# 安全联锁与急停处理（失效安全原则）

## 急停回路
- 现场急停按钮一律用**常闭触点**接入 PLC：输入为 TRUE 表示回路闭合、设备允许运行；
  回路断开（输入变 FALSE）表示急停被按下或断线 —— 断线也必须停机，这叫失效安全（fail-safe）。
- 因此判定逻辑必须是取反后用：
  ```
  #tmpSafetyOk := #EStop AND NOT #Overload;   // EStop 常闭，1=正常
  IF NOT #tmpSafetyOk THEN
      #statFault := TRUE;
  END_IF;
  ```
- 严禁写成 `IF #EStop THEN 停机`（常闭接法下这会导致按急停反而继续运行，属于重大安全缺陷）。
- 安全等级要求 SIL2/PLd 以上时，急停必须双通道 + 交叉监控 + 安全 PLC（F-CPU）或安全继电器，
  普通标准 CPU 的软件联锁不能作为唯一安全措施。

## 故障锁存与复位
- 故障位必须**锁存**（`statFault`），不能在故障消失后自动恢复运行；
  自动恢复会造成设备在无人确认的情况下自启动。
- 复位条件 = 人工复位命令（停止/复位按钮）`AND` 安全条件已恢复 `AND` 无新故障。
- 复位只清故障位，不直接置运行位；重启需要重新按启动。

## 输出安全态
- 任何停机/故障分支都要给输出赋确定值：`#MotorRun := FALSE;`、`#FaultCode := 0;`。
- 不要把输出赋值写在 IF 内部而不写 ELSE，否则故障时输出保持上一扫描周期的值。

## 联锁
- 互斥动作（正转/反转、开阀/关阀）必须做软件互锁 + 硬件互锁（接触器辅助触点）。
- 顺序动作（先启风机再启加热）用状态机实现，不要用定时器串联硬编码，否则异常退出无法复位。

## 故障码
- 故障码用 `Int` 输出给 HMI，一码一因，便于现场定位：
  `16#0001` 急停、`16#0002` 过载、`16#0003` 液位低、`16#0004` 反馈超时。
- 故障码只在故障发生时写入，正常时固定为 0。
